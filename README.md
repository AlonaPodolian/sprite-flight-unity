# Sprite Flight — Unity Learning Project

Beginner 2D game project made with Unity Learn's [2D Beginner Game: Sprite Flight](https://learn.unity.com/course/2d-beginner-game-sprite-flight).

**Status:** In progress  
**Current focus:** Continuing with “Optional bonus features”.

This is a personal learning project.

## Progress

- Completed “Set up your 2D game world” on November 11, 2026.
- Completed “Make a flying obstacle prefab” on November 15, 2026.
- Completed “Random obstacle size, direction, and speed” on November 16, 2026.
- Completed “Steer the player” on November 17, 2026.
- Completed “Build a scoring system” on November 20, 2026.
- Completed “Restart the game with a bang” on November 21, 2026.

## Features

- Mouse-controlled player movement.
- Obstacles with random sizes, directions, and speeds.
- Time-based scoring.
- Player explosion effect and a Restart button.
- High score saved between games using PlayerPrefs.
- Particle effects when obstacles collide.
